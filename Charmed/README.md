# Charmed — dossier de construction

Référence du projet actée par Aurore le 8 septembre 2026. Le jeu de stratégie inventé par son compagnon reste la base. La série originale Charmed est l'univers exclusif.

- `REGLES_ACTEES.md` : règles consolidées ; référence utilisée aussi par l'arbitre logiciel.
- `DECISIONS_ACTEES.md` : décisions remplacées et périmètre de cette étape.
- `CONSTRUCTION.md` : architecture, préparation des parties, procédure de test.
- `canon/` : connaissances sourcées, chronologie et limites de couverture.
- `VALIDATION.md` : résultats des vérifications de cette version.

Le code exécutable reste dans `serveur/charmed/` et `ecrans/modules/charmed.*` : pas de seconde copie concurrente. Les sauvegardes des anciennes versions sont conservées séparément. La refonte artistique du plateau est l'étape suivant le premier essai des mécaniques.
