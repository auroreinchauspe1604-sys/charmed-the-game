## Comment les connaissances sont organisées

Les fichiers Markdown sont les vues de lecture ; les fichiers JSON structurent les connaissances pour le code. Leur degré de détail varie : toutes les fiches ne sont pas encore complètes ni uniformes.

Les fiches de recherche distinguent : identité et catégorie ; description canonique ; épisodes repères ; conditions d’utilisation ; limites et incertitudes ; sources et niveau de vérification ; application proposée au jeu. Une suggestion de gameplay n’est pas une règle canonique.

Les faits utilisés par le contrôle canonique possèdent un identifiant, une affirmation précise, une saison et un épisode, des sources et des limites. Les fiches détaillées apportent du contexte ; elles ne sont pas toutes automatiquement promues en preuves validées.

Dans le code modifié, l’Ange reçoit le corpus de personnages, le corpus magique, les fiches de construction et les deux lots de recherche. Le contrôle canonique accepte les faits du socle, certaines étapes des personnages et les ajouts revus de la bibliothèque. Il reste du travail pour relier tous les mécanismes documentés au contrôle. Le serveur déjà lancé ne charge les nouveaux branchements qu’après redémarrage.
